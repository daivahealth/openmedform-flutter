# Changelog

## 0.1.0

First release.

Pure Dart port of `@openmedform/form-core`, the framework-free engine behind every OpenMedForm
renderer: JSON Pointer and scope resolution, immutable data binding, conditional-rule evaluation,
clinical scoring, record-table summaries, response serialization, the control-registry contract, and
JSON Schema 2020-12 validation behind a swappable `OmfValidator`.

- Ported from form-core `32236d66e350f89d6c76f120007a705963fa3312`; each file records its source.
- 134 conformance cases, generated by calling the real TypeScript implementation rather than
  transcribed by hand, are replayed against this port in CI.
- Accepted differences from upstream are documented rather than left to be rediscovered — including
  one deliberate correction: writes that cross a list address the element instead of replacing the
  whole array.

No Flutter dependency; CI enforces that.
