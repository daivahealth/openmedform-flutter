# openmedform_form_core

Pure Dart port of [`@openmedform/form-core`](https://github.com/daivahealth/openmedform/tree/main/packages/form-core):
the framework-free engine behind every OpenMedForm renderer.

No Flutter dependency — usable from a CLI, a server, or a test. CI enforces that.

## What's in it

| Area | |
|---|---|
| `schema/` | JSON Pointer and scope resolution, `$ref`/`$defs`, label derivation |
| `binding/` | immutable get/set/delete by data path or scope |
| `rules/` | `SHOW`/`HIDE`/`ENABLE`/`DISABLE` against a condition |
| `scoring/` | scored-item collection, totals, per-section subtotals, risk banding |
| `record_table/` | summary-cell derivation, count templating, record seeding |
| `serialization/` | empty-response creation, pruning, submit serialization |
| `validation/` | JSON Schema 2020-12, behind a swappable `OmfValidator` |
| `registry/` | the tester/rank contract renderers dispatch through |
| `i18n/` | translation resolution (ported; no shipped renderer uses it yet) |

## Parity

This is a hand transliteration, so drift is possible. Three things guard against it:

- every file records the `form-core` commit it was ported from;
- **134 conformance cases**, generated by calling the real TypeScript implementation rather than
  transcribed by hand, are replayed against this port in CI;
- accepted differences are written down in [CONFORMANCE.md](../../CONFORMANCE.md) rather than left to
  be rediscovered.

The fixtures pin behaviour that is easy to get wrong by hand. `'yes'` scores but `'YES'` does not. An
absent array counts as `0` while an absent scalar renders as an em dash. A cleared field is removed,
not nulled.

## Validation

`OmfValidator` is an interface; `JsonSchemaValidator` is the default, backed by
`package:json_schema`. It matches Ajv's verdict on every conformance case and flags every path Ajv
flags. Keywords are best-effort — the package exposes none, so they are recovered from diagnostics
and used only to pick a friendly message.

Local validation is advisory. The server re-validates and its answer is authoritative.
